# Voyage 앱 디자인 시스템

Voyage는 밝은 중립 배경과 절제된 청록색 행동색을 사용해, 공동 여행의 의사결정과 계획 정보를 차분하게 정리하는 모바일 우선 제품 시스템입니다.

## 핵심 토큰

```css
:root {
  --bg: oklch(0.985 0.005 247);
  --surface: oklch(1 0 0);
  --fg: oklch(0.18 0.032 265);
  --muted: oklch(0.55 0.04 257);
  --border: oklch(0.928 0.012 249);
  --accent: oklch(0.54 0.10 183);
}
```

## 글꼴

- 표시·본문: `Pretendard, Inter, system-ui, sans-serif`
- 숫자·시간: `ui-monospace, SFMono-Regular, Consolas, monospace` (금액과 시각에만 적용)

## 시각 규칙

1. 캔버스는 옅은 뉴트럴, 내용 단위는 흰색 표면과 1px 테두리로 구분한다.
2. 청록은 저장·생성·확정처럼 한 화면의 핵심 행동에만 사용한다.
3. 상태는 색만으로 전달하지 않고 `확정`, `고려 중`, `마감됨`처럼 텍스트를 함께 표시한다.
4. 모바일에서는 44px 이상 터치 영역과 하단 탭을 사용하고, 데스크톱에서는 240px 사이드바를 사용한다.
5. 일정·금액·정산은 같은 행 안에서 숫자를 우측 정렬하고 tabular numerals를 적용한다.
